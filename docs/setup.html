01 / Use the LDA app

1 min 30 sec

Scan on your Mac, review the findings, export a redacted copy, and restore the edited result with the matching local mapping.

Download video · Read the transcript

Follow the steps
  1. Review and accept the Terms of Service and Privacy Policy, then choose or import a local detection model during setup. Patterns only has narrower coverage.
  2. Add a document in Anonymize, then choose Scan for PII.
  3. Review the detected values, add protection for anything missed, and check Safe Preview.
  4. Choose Export for AI. Send only the reviewed, redacted version, and ask the AI to preserve placeholders.
  5. Save the edited result, open Restore, and use the matching local mapping. Review and save the output.

02 / Use LDA in Codex

1 min 57 sec

Connect once, choose the LDA skill from the slash menu, and select documents in the local picker. Codex works with the prepared redacted text.

LDA 1.0 includes Settings > MCP Setup and its bundled helper. Older releases may not include these controls. This tutorial kit does not install or update LDA.

Download video · Read the transcript

Connect and try the command
  1. Put LDA.app in its final location. In Settings > MCP Setup, choose Codex, save its setup script, and open it in Terminal.
  2. Restart Codex and check the LDA connection.
  3. Type /LDA and select the LDA skill, then add: Summarize the renewal terms. The alternate skill reference is $lda.
  4. Choose files locally, enable optional PII review if wanted, and confirm the Matter locally.
  5. Review the redacted answer. For one document, ask Restore this summary locally and export it. Review the saved output on your Mac.

A Matter name typed into chat is visible to the AI service. Omit it and choose locally to keep the label private. The illustrated entry point is the LDA slash-command skill; an @LDA plugin mention is not assumed.
