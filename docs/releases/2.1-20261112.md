# LDA for macOS 2.1

Version 2.1, build 20261112.1. The app and disk image are Developer ID signed,
notarized by Apple, and stapled for offline verification.

LDA 2.1 adds a choice of Markdown or the source document's format when saving
a redacted copy. Markdown remains the default in the app. Batch output format
is configurable in Settings. The original-format option preserves Word document
structure and produces permanently boxed PDFs and images where coverage can be
verified. CLI batch accepts an explicit `--format markdown|original` option;
omitting it retains the previous CLI output layout.

- Improves confidential-document detection, non-UTF-8 text import, DOCX residue
  removal, PDF coverage accounting, and placeholder restoration.
- Fixes false unboxed-value reports for PDF case variants, and assigns the
  displayed placeholder to the actual printed occurrence.
- Accepts Word documents saved by TextEdit and textutil.
- Preserves previous artifacts and mappings when output settings change.
- Includes regression tests covering the independent review's synthetic probes.

## Known limitations and review

Mapping selection retains the released 2.0 behavior. Re-exporting a document can
make an earlier file restore with later identities. Follow the workflow in
[user guide section 7](../user-guide.md#7-restore-the-original-values-locally) and restore
older returns before generating a new mapping. Keep a file's encrypted mapping
with its own export. This limitation is documented, not claimed to be fixed.
Previously learned keep-visible decisions remain in effect after upgrading.
Published-precedent party handling and neutral-citation behavior are unchanged.

The automated tests and release-build checks are engineering evidence, not a
claim of complete PII recall. Review the findings and the exported copy before
sharing. The current model benchmark has not been rerun for this release.

## Install

Download `LDA-2.1.dmg`, open it, and drag LDA.app into Applications. Requires
Apple silicon and macOS 14 or later. The bundled detector works on Macs with
8 GB of memory. Existing models, matters and preferences are retained.
The bundled LDA V4 model is included; larger models remain optional downloads.
