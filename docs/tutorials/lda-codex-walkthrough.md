# Use LDA in Codex

Illustrated walkthrough. All data is fictional. Silent video with English subtitles.

## 00:00:00.000  Connect LDA once

This illustrated walkthrough shows LDA's slash-command skill and local MCP connection, using fictional data.

Keep LDA in its final location. In MCP Setup, choose Codex, save the setup script, and open it in Terminal.

Restart Codex and check the LDA connection. This needs a build with MCP Setup and the bundled helper.

## 00:00:22.400  Choose LDA from the slash menu

In Codex, type slash LDA and select the LDA skill from the menu.

For example: slash LDA, summarize the renewal terms. Codex also supports the dollar lda skill reference.

Omit the Matter name to choose it privately in LDA. Anything typed in chat is visible to the AI service.

## 00:00:43.646  Choose documents in the local picker

LDA opens a local file picker. Choose the document there instead of attaching an original to the chat.

Turn on the optional PII review to inspect and add protection. Confirm the Matter in LDA's local picker.

## 00:00:59.092  Add protection before continuing

With review enabled, inspect the local highlights and protect anything missed.

Additional terms stay local. Finish the review to continue, or cancel to stop the workflow.

## 00:01:10.692  Codex works with redacted text

Codex receives the prepared redacted text and carries out your instruction.

In this example, it summarizes the renewal terms while keeping the company placeholder. Review the answer and any coverage warnings.

## 00:01:24.215  Ask LDA to restore and export

For an answer based on one document, ask LDA to restore this summary locally and export it.

Use the matching document mapping. The restored text stays local; Codex receives export status.

Review the saved result on your Mac. Keep separate document mappings separate.

## 00:01:43.154  One command, local choices

Start with slash LDA, choose documents locally, review protection, and work with the redacted answer.

Never attach originals, mappings or passwords. These are illustrated steps; exact controls can vary by version.
